# Adaptive Performance Tweaks — MIT

Three APTweaks modules are mirrored on this repository's releases:

- `adaptive_performance_tweaks_gamerules_1.20.1-11.6.1.jar`
- `adaptive_performance_tweaks_items_1.20.1-11.6.1.jar`
- `adaptive_performance_tweaks_player_1.20.1-11.6.1.jar`

Copyright © Markus Bordihn. Licensed **MIT**, as declared in each jar's `META-INF/mods.toml`.
Home: <https://www.curseforge.com/minecraft/mc-mods/adaptive-performance-tweaks>

They are mirrored because their CurseForge projects have third-party distribution switched off,
so the CurseForge API publishes no download URL and no installer can fetch them. The MIT licence
grants the right to redistribute independently of that platform setting:

> copies or substantial portions of the Software.

The jars are mirrored unmodified. If Markus Bordihn would prefer they were not mirrored here,
open an issue and they come out the same day — the sibling module APTweaks Core does allow
distribution, so enabling it on these three would let us drop the mirror entirely.
